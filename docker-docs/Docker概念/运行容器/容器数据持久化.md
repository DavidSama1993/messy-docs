# 容器数据持久化（Persisting container data）

## 讲解

容器启动时，会使用镜像提供的文件和配置。每个容器都可以新建、修改、删除文件，并且这些操作不会影响其他容器。**一旦容器被删除，容器内部所有改动的文件也会跟着消失。**

容器这种临时特性虽然很有用，但在需要长久保存数据时就会遇到问题。比如重启数据库容器，我们不希望数据库是空的。那该如何持久化文件？

### 容器卷（Container volumes）

卷（volume）是一种存储机制，可以让数据独立于单个容器的生命周期保存。可以理解为：在容器内部到宿主机外部建立一个快捷方式或者软链接。

举个例子，创建名为 `log-data` 的卷：

```
$ docker volume create log-data
```

启动容器时，把这个卷挂载到容器内的 `/logs` 目录：

```
$ docker run -d -p 80:80 -v log-data:/logs docker/welcome-to-docker
```

如果 `log-data` 卷不存在，Docker 会自动帮你创建。

容器运行时，写入 `/logs` 的所有文件都会保存到这个卷里，独立于容器本身。就算删掉这个容器，再新建一个容器挂载同一个卷，之前的数据仍然存在。

> 
> **使用卷共享文件**
> 同一个卷可以挂载到多个容器，用来在容器之间共享文件，适合日志聚合、数据流水线、事件驱动类应用。

### 卷管理

卷拥有独立于容器的生命周期，根据业务数据不同，卷体积可能变得很大。下面是常用管理命令：

- `docker volume ls` — 列出所有卷
- `docker volume rm <volume-name-or-id>` — 删除卷（卷没有被任何容器挂载时才可以执行）
- `docker volume prune` — 删除所有未被使用（未挂载）的卷

## 动手实践

本节练习创建并使用卷，持久化 Postgres 容器的数据。Postgres 运行时数据存放在 `/var/lib/postgresql`，把卷挂载到这个路径，重启容器数据就不会丢失。

### 使用卷

1. 安装 Docker Desktop
2. 启动 Postgres 容器，挂载数据卷

```
$ docker run --name=db -e POSTGRES_PASSWORD=secret -d -v postgres_data:/var/lib/postgresql postgres:18
```

后台启动数据库，设置密码，并将卷挂载到 Postgres 的数据目录。

3. 进入容器连接数据库

```
$ docker exec -ti db psql -U postgres
```

4. 在 psql 终端执行建表、插入数据：

```
CREATE TABLE tasks (
    id SERIAL PRIMARY KEY,
    description VARCHAR(100)
);
INSERT INTO tasks (description) VALUES ('Finish work'), ('Have fun');
```

5. 查询验证数据

```
SELECT * FROM tasks;
```

输出：

```
 id | description
----+-------------
  1 | Finish work
  2 | Have fun
(2 rows)
```

6. 退出 psql

```
\q
```

7. 停止并删除容器。容器虽然删掉，但数据保存在 `postgres_data` 卷中

```
$ docker stop db
$ docker rm db
```

8. 新建容器，挂载同一个卷恢复数据

```
$ docker run --name=new-db -d -v postgres_data:/var/lib/postgresql postgres:18
```

> 
> 这里不再传入 `POSTGRES_PASSWORD`，因为该环境变量仅在数据库**首次初始化**时生效。

9. 查询，验证数据还在

```
$ docker exec -ti new-db psql -U postgres -c "SELECT * FROM tasks"
```

### 查看卷内容

Docker Desktop 面板可以直接查看卷内文件，也支持导出、导入、清空、删除、克隆卷。

1. 打开 Docker Desktop，切换到 **Volumes** 页面，能看到 `postgres_data`
2. 点击卷名称进入详情
3. `Stored Data`：浏览卷内文件；`Container in-use`：查看正在使用该卷的容器、镜像、端口、挂载目标（target，即容器内挂载路径）；`Exports`：导出卷。双击文件查看内容、修改文件。
4. 右键文件可以保存或删除。

### 删除卷

删除卷前，必须先解除挂载（容器停止/删除）。强制删除容器：

```
$ docker rm -f new-db
```

删除卷几种方式：

- 在 Docker Desktop 卷面板点击 Delete Volume
- 命令删除指定卷

```
$ docker volume rm postgres_data
```

- 清理所有闲置卷

```
$ docker volume prune
```
