# 端口发布与暴露（Publishing and exposing ports）
## 讲解
如果你跟着前面的教程学习，就会知道容器为应用的各个组件提供隔离进程：React 前端、Python API、Postgres 数据库，各自运行在独立沙箱环境，和宿主机完全隔离。隔离有利于安全和依赖管理，但也带来一个问题：**你无法直接访问容器内部服务**，比如浏览器打不开容器里的网页。

这就是**端口发布（port publishing）**的作用。

### 端口发布
端口发布通过配置转发规则，打破一部分网络隔离。举个例子：把宿主机的 `8080` 端口流量转发到容器内部的 `80` 端口。端口发布在创建容器时，通过 `docker run` 的 `-p`（全称 `--publish`）参数实现。语法：
```console
$ docker run -d -p HOST_PORT:CONTAINER_PORT nginx
```
- `HOST_PORT`：宿主机端口，用来接收外部流量
- `CONTAINER_PORT`：容器内部服务监听的端口

示例：将容器 80 端口映射到宿主机 8080
```console
$ docker run -d -p 8080:80 nginx
```
此时访问宿主机 8080 的所有流量，都会转发给容器内的 80 端口。

> ⚠️ 重要提示
> 默认情况下，映射的端口会监听宿主机**所有网卡（0.0.0.0 / ::）**，只要能访问到这台机器的流量都可以访问该服务。数据库等敏感服务映射端口时一定要谨慎。

### 绑定到指定宿主机IP
端口默认监听全部网卡。你可以指定绑定到某个IP，格式把IP写在最前面：
```console
$ docker run -d -p 127.0.0.1:8080:80 nginx
```
完整格式：`HOST_IP:HOST_PORT:CONTAINER_PORT`
- `HOST_IP`（可选）：绑定的宿主机地址。填 `127.0.0.1` 代表仅本机可访问；也可以填网卡IP，只允许该网卡收到的流量访问。
- `HOST_PORT` / `CONTAINER_PORT` 含义同上。

Docker Compose 中也支持这种写法：
```yaml
services:
  app:
    image: docker/welcome-to-docker
    ports:
      - "127.0.0.1:8080:80"
```

### 使用临时端口（ephemeral ports）
有时候你只想开放端口，不在乎宿主机用哪个端口，让Docker自动分配。写法就是省略宿主机端口：
```console
$ docker run -p 80 nginx
```
容器启动后，执行 `docker ps` 查看分配到的端口：
```console
docker ps
CONTAINER ID   IMAGE         COMMAND                  CREATED          STATUS          PORTS                    NAMES
a527355c9c53   nginx         "/docker-entrypoint.…"   4 seconds ago    Up 3 seconds    0.0.0.0:54772->80/tcp    romantic_williamson
```
这个例子里，宿主机分配到 `54772` 端口访问容器。

### 一次性发布所有暴露端口
制作镜像时，`EXPOSE` 指令用来声明应用会用到哪些端口。**EXPOSE 只是声明，不会自动对外发布端口**。

使用 `-P`（全称 `--publish-all`），可以把镜像里所有 `EXPOSE` 声明的端口全部自动映射到宿主机临时端口。开发、测试环境用来规避端口冲突很方便：
```console
$ docker run -P nginx
```

## 动手实践
本次实操，分别用命令行和 Docker Compose 发布容器端口，部署一个 Web 应用。
### 使用 Docker CLI
1. 安装 Docker Desktop
2. 终端执行命令启动容器：
```console
$ docker run -d -p 8080:80 docker/welcome-to-docker
```
前面的 `8080` = 宿主机端口；后面 `80` = 容器内部服务监听端口。这条命令把宿主机8080绑定到容器80。
3. 在 Docker Desktop 面板的 Containers 页面查看端口映射。
4. 点击容器端口列链接，或者浏览器打开 http://localhost:8080 访问页面。

### 使用 Docker Compose
同样的应用，用 Compose 启动：
1. 新建文件夹，在里面创建 `compose.yaml`
```yaml
services:
  app:
    image: docker/welcome-to-docker
    ports:
      - 8080:80
```
`ports` 支持多种语法，这里和 `docker run` 一样使用 `宿主机端口:容器端口`。
2. 终端进入该目录
3. 执行 `docker compose up` 启动服务
4. 浏览器访问 http://localhost:8080
