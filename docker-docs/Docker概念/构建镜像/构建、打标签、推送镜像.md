# 构建、打标签并推送镜像

## 讲解

在本文中，你将学习：

- 构建镜像：基于 Dockerfile 生成镜像的过程
- 镜像打标签：给镜像命名，镜像名称同时决定它可以分发到哪个镜像仓库
- 发布镜像：将新构建好的镜像分发、共享到容器镜像仓库

### 构建镜像

绝大多数场景都是通过 Dockerfile 构建镜像。最基础的 `docker build` 命令如下：

```
docker build .
```

命令末尾的 `.` 代表**构建上下文（build context）**的路径或 URL。构建器会在这个路径下寻找 Dockerfile，以及文件中引用的其他资源。

执行构建时，如果需要，构建器会先拉取基础镜像，然后依次执行 Dockerfile 里定义的所有指令。

只用上面这条命令构建出来的镜像没有名字，只能通过镜像 ID 引用，示例输出：

### 镜像打标签

打标签就是给镜像设置一个方便记忆的名称。镜像全名遵循固定格式：

```
[HOST[:PORT_NUMBER]/]PATH[:TAG]
```

- `HOST`：可选，镜像仓库地址；不写时默认使用 Docker 公共仓库 `docker.io`
- `PORT_NUMBER`：仓库端口，仅当指定仓库域名时才需要
- `PATH`：镜像路径，由斜杠分隔；Docker Hub 格式为 `[命名空间/]仓库名`。命名空间一般是用户名或组织名；不指定命名空间则默认是 `library`（Docker官方镜像的命名空间）
- `TAG`：自定义可读标识，用来区分版本、变体；不指定标签默认是 `latest`

镜像名称示例：

- `nginx`，等价于 `docker.io/library/nginx:latest`：从 `docker.io`、`library` 命名空间拉取 nginx 镜像，标签 latest
- `docker/welcome-to-docker`，等价于 `docker.io/docker/welcome-to-docker:latest`
- `ghcr.io/dockersamples/example-voting-app-vote:pr-311`：从 GitHub 容器仓库 ghcr.io 拉取镜像

构建时通过 `-t / --tag` 参数直接打标签：

```
docker build -t my-username/my-image .
```

镜像已经构建完成后，可以用 `docker image tag` 追加新标签：

```
docker image tag my-username/my-image another-username/another-image:v1
```

### 发布镜像

镜像构建并打好标签之后，就可以推送到镜像仓库，使用 `docker push`：

```
docker push my-username/my-image
```

几秒内镜像的所有层就会上传到仓库。

> 
> **需要登录认证**
> 在推送镜像前，必须先完成仓库登录，使用 `docker login` 命令。

## 动手实践

本次实操，使用提供的 Dockerfile 构建简单镜像并推送到 Docker Hub。

### 准备工作

1. 获取示例项目
有 Git 可以直接克隆仓库，否则下载压缩包，二选一：
**Git 克隆**

```
$ git clone https://github.com/docker/getting-started-todo-app
```

**下载源码**
[Download the source](https://github.com/docker/getting-started-todo-app/raw/cd61f824da7a614a8298db503eed6630eeee33a3/app.zip)

2. 安装 Docker Desktop
3. 如果还没有 Docker 账号，去 Docker Hub 注册，并且在 Docker Desktop 内登录该账号。

### 构建镜像

你已经在 Docker Hub 建好仓库，现在构建镜像并推送。

1. 在示例项目根目录打开终端，执行下面命令，把 `YOUR_DOCKER_USERNAME` 替换为你的 Docker Hub 用户名：

```
$ docker build -t <YOUR_DOCKER_USERNAME>/concepts-build-image-demo .
```

示例：用户名是 `mobywhale`

```
$ docker build -t mobywhale/concepts-build-image-demo .
```

2. 构建完成，查看本地镜像列表：

```
$ docker image ls
```

输出示例：

```
REPOSITORY                             TAG       IMAGE ID       CREATED          SIZE
mobywhale/concepts-build-image-demo    latest    746c7e06537f   24 seconds ago   354MB
```

3. 查看镜像构建历史（分层信息）：

```
$ docker image history mobywhale/concepts-build-image-demo
```

输出会展示所有镜像层，区分你新增的层和继承自基础镜像的层。

### 推送镜像

```
$ docker push <YOUR_DOCKER_USERNAME>/concepts-build-image-demo
```

如果报错 `requested access to the resource is denied`，检查是否登录、镜像标签里的用户名是否正确。
等待上传完成，镜像就存到 Docker Hub 仓库了。
