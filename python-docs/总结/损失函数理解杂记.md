# MSE和MAE的替代关系

​	MAE 不但没被淘汰，工程里依然大量在用。它俩是两种性格，按场景选，不是替代关系。

## 1、为什么说 “不能替代”

- **MSE 优化的是预测的 “均值”**：误差平方放大，模型会拼命压低大误差样本 → 预测结果向 “平均” 靠拢。
- **MAE 优化的是预测的 “中位数”**：只算绝对差距，不放大 → 预测结果更抗异常值。

> 一句话：数据里有脏点 / 离群点，MAE 给的结果更稳；数据干净，MSE 更准。

## 2、工程里真实的选型

| 场景                                     | 用谁                        |
| ---------------------------------------- | --------------------------- |
| 通用回归（价格、销量，数据干净）         | MSE（默认首选）             |
| 数据有噪声、离群点多                     | MAE                         |
| 你更关心 “大多数样本” 而不是被极端值带偏 | MAE                         |
| 金融、风控、异常检测类                   | 常选 MAE                    |
| 既要平滑又要抗离群                       | **Huber Loss（Smooth L1）** |

### 2.1、工程里真正的主流其实是 “折中”

MSE 梯度随误差增大而增大，对离群点太重；MAE 梯度恒定、在 0 点不可导。 所以工程里大量用 **Huber Loss（也叫 Smooth L1）**：

- 误差小的时候表现得像 MSE（梯度平滑、收敛快）
- 误差大的时候表现得像 MAE（不被离群点带偏）

> 例子：YOLO 系列目标检测的框回归损失就是 Smooth L1，本质上就是 Huber。

## 3、纠正常见误区

（1）MAE 和 MSE 在**回归任务**里竞争；但如果是**分类任务**，两者都不是主流，用的是 **CrossEntropy（交叉熵）**，那个才是另一码事。

（2）MSE 是默认选项，MAE 是抗脏数据选项，Huber 是工程折中选项。它们各自活着，没有谁淘汰谁。

（3）你之前聊的 ETL 思路刚好对应：**数据脏 → 先 ETL 清洗 + 再用 MAE 兜底；数据干净 → MSE 就够了。** 两层防护，不是二选一。

## 4、加入Smooth L1后

​	**加入Smooth L1后三种损失在 “误差多大时损失涨多快” 上的区别**

![image-20260917115732237](C:\Users\17679\Desktop\MSE&MAE&Smooth L1.png)

看曲线的关键：**误差大时（两侧），MSE 剧烈上翘、MAE 和 Smooth L1 都是缓坡；误差小时（中间），Smooth L1 和 MSE 一样是平滑曲线，MAE 是尖角。**

### 4.1、Smooth L1 是什么

就是 **Huber Loss**（δ=1 的经典形式）：

- 误差小（| 误差 |≤δ）：按 **0.5・误差 ²** 算 → 像 MSE
- 误差大（| 误差 |>δ）：按 **| 误差 |−0.5δ** 算 → 像 MAE

它本质上是**在 MSE 和 MAE 之间取了个折中**。

### 4.2、三选一怎么抉择

| 情况                                              | 选谁          | 原因                                  |
| ------------------------------------------------- | ------------- | ------------------------------------- |
| 数据干净、无离群点                                | MSE           | 收敛快、梯度平滑，数学性质最好        |
| 数据脏、离群点多，且不在乎小误差精确度            | MAE           | 对大误差只线性惩罚，最抗离群          |
| 数据有离群点，**同时**希望小误差也能被精细优化    | **Smooth L1** | 小误差按平方精细调整 + 大误差不被带偏 |
| 目标检测等 “误差可大可小” 的任务（YOLO 框回归等） | **Smooth L1** | 大误差时梯度**有界**，不会梯度爆炸    |

### 4.3、工程上的实际偏好（重点）

1. **大误差梯度爆炸问题**：MSE 的梯度 = 2× 误差，误差为 10 时梯度 20，训练容易震荡甚至发散；Smooth L1 在大误差时梯度恒为 ±1，**天然防爆炸**。
2. **小误差收敛问题**：MAE 在小误差附近梯度也是 ±1（不随误差变小而减小），收敛慢、在 0 点不可导；Smooth L1 在小误差时梯度线性缩小，**收敛更细腻**。
3. **超参数**：Smooth L1 多一个 δ（PyTorch 里 `nn.SmoothL1Loss` 叫 `beta`，默认 1.0）。**δ 大 → 更像 MSE；δ 小 → 更像 MAE**，可以按数据噪声程度调。

## 5、一句话总结

> 数据干净 → MSE；数据脏且要绝对抗离群 → MAE；**数据脏但还想精细训练小误差 → Smooth L1（大多数工程场景的默认折中）**。

一个实际经验：做回归时不知道数据脏不脏，先跑 Smooth L1 通常是最稳的开局，再根据验证集表现微调 β 或换 MSE/MAE。



# 交叉熵

​	**这块正好是分类任务的另一条赛道，跟前面的回归损失不是一个维度**

横轴不再是 “误差”，而是**预测概率 p（0~1）**，因为交叉熵处理的是分类问题，对象是概率而不是数值偏差：

![image-20260917142117105](C:\Users\17679\Desktop\交叉熵.png)

|            | 回归损失               | 交叉熵                       |
| ---------- | ---------------------- | ---------------------------- |
| 解决的任务 | 预测数值（房价、体重） | 分类（是猫还是狗、好评差评） |
| 比较的对象 | 预测值 vs 真实数值     | 预测概率 vs 真实类别         |
| 输出的东西 | 任意实数               | 0~1 的概率                   |

**MSE/MAE 管 “量多准”，交叉熵管 “类分对没有”。**

## 1、读图关键（3 个点）

1. **交叉点 p=0.5**：两条 BCE 曲线都在 0.693（ln2）处相交。p=0.5 就是 “完全没把握”，此时损失是固定的 0.693，这个数就是模型的 “起点”；
2. **越自信损失越低**：p 越接近 1（真实 = 1），损失趋近 0；**越自信地犯错，损失爆炸式上涨**（左侧红色线 p→0 时冲到 3.0，还在继续涨）；
3. **对比灰色虚线 MSE**：p→0 时 MSE 曲线已经 “躺平” 在 0.9 附近，梯度极小 —— 这就是分类任务**不用 MSE 的核心原因：越错越学不动（梯度消失）**，而 BCE 越错梯度越大、惩罚越狠。

## 2、BCE 和 CE 到底啥关系

- **二元交叉熵 BCE**（配合 sigmoid）：`L = -[y·ln(p) + (1-y)·ln(1-p)]`，两个类都要算；
- **交叉熵 CE**（配合 softmax，多分类）：`L = -ln(p_正确类别)`，只对 “正确答案” 那一路算。

> 公式上：**CE 是多分类的通用版，BCE 是二分类的特例**（K=2 时 CE 展开就是 BCE）。PyTorch 里 `CrossEntropyLoss` 和 `BCELoss` 是两个接口，别混。

怎么抉择（结合你之前房价 / 大数据的例子）

| 场景                                   | 用什么                       | 为什么                                       |
| -------------------------------------- | ---------------------------- | -------------------------------------------- |
| 二分类：垃圾邮件、信用卡欺诈、感冒与否 | BCE（sigmoid+BCE）           | 两个类，天然匹配                             |
| 多分类：手写数字 0-9、猫狗鸟           | CE（softmax+CrossEntropy）   | 输出所有类概率，取正确类的负对数             |
| 多标签：一张图同时有猫又有狗           | **每个标签单独 BCE**         | 标签互斥用 softmax，不互斥要逐个 sigmoid+BCE |
| 类别极不均衡：欺诈样本只占 1%          | CE/BCE 的加权版或 Focal Loss | 让罕见类也能被充分学习                       |

## 3、一句话总结

> 回归看 “偏差大小”→ MSE/MAE/Smooth L1；分类看 “概率对不对”→ BCE（二类）/ CE（多类）。 交叉熵的哲学：**宁可让你不确定（p=0.5），也不能让你自信地错**—— 自信地错，损失涨得最狠。
